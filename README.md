## 📖 Sobre o Projeto

O **Ajuda Imediata** é uma plataforma criada para centralizar, facilitar e dar transparência ao processo de doações. Em momentos de crise ou necessidade extrema, a agilidade na conexão entre doadores e instituições (ou pessoas) é fundamental. Nosso objetivo é reduzir a burocracia e fazer a ajuda chegar a quem mais precisa no menor tempo possível.

## ✨ Funcionalidades

* **Busca de Campanhas:** Filtre pelo seu bairro.
* **Transparência:** Acompanhamento de doações em tempo real.
* **Design Responsivo:** Acessível e fácil de usar em qualquer dispositivo, do celular ao desktop.
* **Cadastro Rápido:** Fluxo simplificado, não é necessário criar conta.

## 🚀 Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando as seguintes tecnologias:

* **[Next.js](https://nextjs.org/)** - Framework React para a interface e rotas.
* **[React](https://reactjs.org/)** - Biblioteca JavaScript para construção da UI.
* **[Tailwind CSS](https://tailwindcss.com/)** - Estilização utilitária e responsiva.
* **[TypeScript](https://www.typescriptlang.org/)** - Tipagem estática para maior segurança do código.
* **PrismaORM** - Para fazer uma ponte entre o código e o banco de dados.
* **PostgreSQL** - Banco de Dados;

## 🛠️ Como Executar Localmente
